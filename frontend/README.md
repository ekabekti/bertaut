# Frontend BERTAUT

Etalase statis — tanpa proses build, tanpa dependensi.

- `index.html` — struktur (login, etalase, modal, laci pengaturan, palet)
- `styles.css` — tema obsidian + kuningan
- `app.js` — logika: boot publik-vs-lokal, auth, CRUD, palet, jam WIB

Dihidangkan oleh `backend/server.js` sebagai `/`, atau dibuka langsung
(`file://` → moda lokal mandiri).
